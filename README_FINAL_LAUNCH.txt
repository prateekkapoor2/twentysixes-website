RESPONSIVE SUPPORT
Responsive CSS includes wide desktop, laptop, tablet, mobile and narrow-phone breakpoints, including targeted rules for 320–380px phones, common phone widths, tablet portrait/landscape and large desktop screens. Static source and package integrity checks passed. A rendered cross-viewport browser test could not be completed in this execution environment because Chromium navigation is blocked by the runtime administrator; therefore do not treat physical-device QA as complete. Before launch, preview at 320, 360, 390, 430, 768, 820, 1024, 1280, 1440 and 1920 CSS pixels and confirm no horizontal overflow, then test iOS Safari and Android Chrome.

Visitors without a configured email application can use the direct email link. Add a form backend only if a server-side submission flow is wanted.
